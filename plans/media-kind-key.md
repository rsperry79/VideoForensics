# Media kind in the MediaItems unique key

Status: implemented on `fix/media-kind-key` (commit 92ea079a), merged into `wip` (0f149f54). Plan written after the work, at the user's request, so the review happens after implementation. Note this in the PR.

## Problem
A time-lapse loop's MediaItem uses the segment start as RecordedAtUtc. The unique key (DeviceId, RecordedAtUtc) rejects it when a snapshot or clip already has that instant, so the segment fails on every check and the check never completes. Live log: `UNIQUE constraint failed: MediaItems.DeviceId, MediaItems.RecordedAtUtc`, 04:25 onward.

## Decision
Add `MediaKind` (Clip, Snapshot, Timelapse, Still) to MediaItems and to the unique key: (DeviceId, RecordedAtUtc, MediaKind). Chosen by the user over adding MediaFormat, which does not separate loops from clips (both are mp4), and over adding FileName.

## Units
1. Failing test: a snapshot and a loop at one instant both save; two clips at one instant are rejected. Done (MediaItemKindKeyTests). Red: compile error, MediaKind missing.
2. Entity, constants, configuration: MediaKinds, MediaItem.MediaKind, config with default "Clip" and the new index. Done.
3. Migration AddMediaKind (generated by EF), with a backfill UPDATE: jpg to Snapshot, image/png to Still, FileName like %snapshot-loop% to Timelapse, else Clip. Done.
4. Writers set the kind: Ring clip (Clip), Ring jpg (Snapshot), snapshot service (Snapshot), time-lapse loop (Timelapse), still capture (Still). Done.
5. Clip lookup matches only rows of the same kind (VideoForensicsDataClient). Done.
6. Tests: data database 1007 pass, SQLite 42 pass, data core 261 pass, hosting 1251 pass, Ring provider 754 pass, client core 308 pass. Done.

## Review (Sonnet, read-only, against 92ea079a)
- MediaItemDto had no MediaKind, so remote reads returned every row as Clip. Fixed: DTO and both mappings carry it (41af45cb).
- Backup export and import dropped the kind. Decided by the user: export MediaKind, and refuse backups whose items lack it, before any write. Old backups must be exported again. Done (f154a46d).
- Backfill matched format case-sensitively. Fixed: lower(format) IN ('jpg','jpeg').
- Rollback (Down) recreates the stricter index and fails while other kinds share an instant with a clip. Noted in the migration.
- The snapshot diff adds ValueGeneratedOnAdd for AwaitingDingId. EF adds it because of HasDefaultValue. Harmless, kept.
- Loop detection by FileName "snapshot-loop" checked: the writer produces that name.
