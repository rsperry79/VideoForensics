Critical Concern for Polly Phase 2:
================================================================

Bearer Token Lifecycle vs. Polly Policy Lifecycle:

ISSUE: Policy is attached to HttpClient at startup
      Token is obtained per-request

      If Polly circuit breaker opens (429 Hard Ban):
      1. Circuit opens at startup time
      2. Hard ban persists in Polly state
      3. Bearer token may expire while circuit is open
      4. Circuit opens again when reopened (stale token)

SOLUTION: Token obtained BEFORE policy decision
         Token injection happens during request preparation
         Policy sees fresh token in Authorization header

Current Order (CORRECT):
```
Request → Token Injection → Policy Evaluation → Send
```

If reversed (WRONG):
```
Request → Policy Evaluation → Token Injection → Send
         (policy might be closed but token stale)
```

Hard-Ban State Interaction with Policies:
================================================================

Problem (from DEEP_CODE_REVIEW.md):
- HttpClient policies don't know about persisted hard-ban state
- Polly circuit breaker is in-memory only
- If app restarts, Polly loses circuit state but file has ban

Solution Requirement (Task 2.1):
1. On startup: Load hard-ban state from disk
2. If active: Initialize Polly circuit breaker to Open state
3. If expired: Initialize Polly circuit breaker to Closed state
4. During operation: Polly manages throttle escalation, writes to disk

Integration Point:
```csharp
AddVideoForensicsClientApi()
{
    // Load persisted hard-ban state
    var hardBanExpiry = await _httpUtility.GetHardBanUntilUtcAsync();

    var circuitPolicy = Policy
        .Handle<HttpRequestException>(ex => ex.StatusCode == 429)
        .OrResult<HttpResponseMessage>(r => r.StatusCode == TooManyRequests)
        .CircuitBreakerAsync<HttpResponseMessage>(
            handledEventsAllowedBeforeBreaking: 3,
            durationOfBreak: TimeSpan.FromHours(1),
            onBreak: (outcome, timespan) =>
            {
                // Write to disk when circuit opens
                _httpUtility.RecordHardBan(DateTime.UtcNow.Add(timespan));
            },
            onReset: () =>
            {
                // Clear disk state when circuit resets
                _httpUtility.ClearHardBan();
            });

    // Initialize to current state
    if (hardBanExpiry > DateTime.UtcNow)
    {
        // Initialize circuit to Open (respect persisted ban)
        // Polly 8.0+ supports: circuitPolicy.SetStateAsync(CircuitState.Open, hardBanExpiry)
    }

    return services;
}
```
